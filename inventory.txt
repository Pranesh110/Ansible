Inventory file is the one where we keep all the managed node details that to be find by the COntrol node

We can keep it on inventory.ini or in YAML format

file looks like
vim inventory.ini
Servers
ansible@privateip
ec2-user@privateip

Inventory.ini file can be anywhere in the machine we need to pass teh apth in ansible

[linux] --group name 
linux1 ansible_host=10.0.0.157 ansible_user=ec2-user

[windows] --group name
win1 ansible_host=10.0.0.200 ansible_user=Administrator


[windows:vars]
ansible_connection=winrm
ansible_port=5986
ansible_winrm_scheme=https
ansible_winrm_transport=ntlm
ansible_winrm_server_cert_validation=ignore
ansible_password={{ vault_windows_password }}

Replace the Windows IP and username with your actual values. The password variable will be defined in an encrypted file.

2. Create an encrypted password file

On your Amazon Linux Control Node, create a file:

ansible-vault create windows-secrets.yml

Enter a vault password when prompted. An editor opens; add:

vault_windows_password: "YourActualWindowsPassword"

Save and exit. Ansible Vault encrypts the file so the Windows password isn't stored in plain text.

3. Test the Windows connection

Install the WinRM Python library on the Control Node if needed:

python3 -m pip install pywinrm

4. Test the connection

ansible -i inventory.inipath -m ping all/specific server

For your inventory containing both machines, use:

ansible linux -i inventory.ini -m ping
ansible windows -i inventory.ini -m ansible.windows.win_ping \
  -e @windows-secrets.yml --ask-vault-pass

  {Need to use ansibile.windows.win_ping module for windows}
